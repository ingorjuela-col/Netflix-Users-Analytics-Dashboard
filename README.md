# 📊 Netflix Users Analytics Dashboard

Dashboard interactivo desarrollado con **HTML, CSS y JavaScript** para analizar y visualizar datos de usuarios de Netflix.

### 🔎 ¿Qué permite hacer?

* Cargar archivos CSV o pegar datos desde Excel/Markdown.
* Generar indicadores y gráficos automáticamente.
* Analizar suscripciones, comportamiento y distribución geográfica.
* Crear el **Grupo Etario** a partir de la edad.

### 🛠️ Tecnologías

**HTML5 · CSS3 · JavaScript · Visualización de datos**

Proyecto desarrollado como ejercicio práctico de **analítica de datos y visualización**, con una interfaz inspirada en la identidad de **Universidad El Bosque**.
